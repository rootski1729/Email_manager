ICON PLACEHOLDER - 16x16
========================

To create your extension icons:

1. Create a 512x512 base image with:
   - Purple gradient background (#667eea to #764ba2)
   - White envelope icon in center
   - "EF" or full "EmailFilter Pro" text

2. Export as PNG at different sizes:
   - icon16.png (16x16px)
   - icon48.png (48x48px)
   - icon128.png (128x128px)

3. Replace this file with actual PNG

Recommended tools:
- Free: Canva.com, GIMP, Inkscape
- Paid: Adobe Photoshop, Illustrator
- Online: favicon.io, icon-icons.com

Color scheme:
- Primary gradient: #667eea → #764ba2
- Icon color: #FFFFFF (white)
- Background: Transparent or gradient
